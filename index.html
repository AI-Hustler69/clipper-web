Clipper

Clipper is a private, non-commercial desktop tool used by a single creator. It turns the owner's recorded game streams into short vertical clips and manages the owner's own YouTube channels. It runs only on the owner's computer. It is not offered to the public, has no other users and does not access any channel the owner does not manage.

What it does

  • Fills in metadata for videos the owner uploaded: title, description, tags, category, language, made-for-kids and altered-content declarations.
  • Schedules publishing times of the owner's private videos.
  • Sets custom thumbnails, uploads caption files (.srt) and adds videos to the owner's playlists.
  • Uploads videos produced by the owner, always as private, so the owner can review them before publishing.
  • Reads view counts and YouTube Analytics reports of the owner's own videos to decide which formats work and to plan the schedule.

The tool only carries out jobs the owner prepared and confirmed (which video, which text, which publishing time). It never comments, likes, subscribes or interacts with other users, and never deletes videos.

Why more quota

The owner publishes many short videos per day across several own channels. Each metadata and schedule update costs 50 units and each caption upload about 450, so the default 10,000 units per day are used up before all of the owner's own videos are prepared. No data is collected about other users.
