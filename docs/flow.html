Clipper – user flows

There is a single user: the channel owner. Every change on YouTube comes from a job the owner prepared and approved.

A. One-time sign-in

Owner
1Run “youtube.bat login <channel>”Browser opens Google sign-in.
→
2Google consent screenOwner picks own account + channel, sees requested scopes, clicks Allow.
→
3Token stored locallyRefresh token saved only on the owner's PC.
→
4Revoke any timeGoogle Account → Security → Third-party access.

B. Daily: clips → metadata and schedule

Owner + clipper
1Clips are producedStream → transcription → vertical clips (local, no API).
→
2Owner reviewsApproves / rejects each clip (swipe UI). Job file with title, description, tags, time.
→
3UploadOwner uploads files in YouTube Studio (kept private), or the tool uploads as private.
Owner + tool
4Run youtube.batReads own videos (videos.list), matches them by file name.
→
5Preflight listShows every planned change and the quota estimate.
→
6Owner confirms “ano”Or an optional night run the owner scheduled (metadata and schedule only, no uploads).
→
7API callsvideos.update (metadata, publishAt), thumbnails, captions, playlist.
→
8Video goes liveAt the scheduled time, on the owner's channel.

C. Weekly: learning from results

Tool
1Read statsvideos.list statistics + Analytics reports.query for own videos.
→
2Local reportWhich formats, lengths and streamers perform best.
→
3Owner decidesPlans next clips and schedule. No automatic publishing.
