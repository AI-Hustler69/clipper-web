Clipper – architecture

Private single-user tool. Runs only on the owner's Windows PC and manages only the owner's own YouTube channels.

Owner's PC (Windows 11)
1. Clip production (clipper)Records the owner's chosen game streams, transcribes them locally (Whisper), cuts vertical 9:16 clips with FFmpeg, burns in subtitles. No Google API calls.
2. Job filesFor each approved clip: file name, title, description, tags, category, language, schedule time (JSON). Prepared and reviewed by the owner.
3. Channel manager (youtube.bat / Python)Matches jobs to the owner's uploaded videos, shows a preflight list of all changes, applies them after the owner types “ano” (yes) or in an optional night run the owner scheduled (metadata and schedule only). Never deletes videos, never interacts with other users.
Local storageOAuth refresh tokens and client secret stored only on this PC (outside any repository). Run results and channel statistics in the owner's private Git repository.
